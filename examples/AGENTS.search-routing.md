# 联网搜索

- 查找明确网页、官方文档、数据页、当前版本资料或简单事实时，优先使用 Exa 的 `web_search_exa`。
- 已经知道 URL、需要核对页面正文或上下文时，使用 `web_fetch_exa`。
- 普通开放式问题需要边搜索边解释、比较或综合时，使用 `grok_search`（Grok 4.3）。
- 只有在来源冲突、需要广泛交叉验证，或用户明确要求深入调查时，才使用 `grok_deep_search`（Grok 4.20 Medium）。
- Exa 与 Grok 是按需协作：先用 Exa 找准来源，只有需要综合或结果不足时才升级到 Grok；不要对简单问题重复调用全部工具。
- 只有问题明确涉及 X 帖子、舆情或实时讨论时，才为 Grok 搜索启用 `include_x=true`。
